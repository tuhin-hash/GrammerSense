# Grammar Error Detection & Correction — Modern Web UI

A responsive single-page web application built with **React**, **Vite**, and **TailwindCSS**.

## Features

1. **Interactive Live Editor**:
   - Live text input with word & character counters.
   - Quick-select preset dropdown including mandatory test benchmark sentences.
   - Shortcut support (`Ctrl + Enter` to analyze).

2. **Visual Word-Level Diff**:
   - Color-coded diff showing deleted erroneous words in red strikethrough and inserted corrections in bold green highlight.
   - 1-click copy for the recommended correction.

3. **Detected Error Cards**:
   - Clear classification tags for each error.
   - **Verification Tier Badges**:
     - `[DIRECTLY IDENTIFIED]`: Verified by grammatical/morphological rules.
     - `[INFERRED]`: Inferred by neural model alignment and contextual fluency.
   - Pedagogical explanations describing *why* the error occurred.
   - "Apply Fix" button to apply individual edits directly into the input text.

4. **Alternative Candidates Carousel**:
   - Inspect alternative sentences generated by beam search.
   - Displays model confidence percentage and edit distance.
   - 1-click candidate selection.

5. **Interpretable Quality Metrics**:
   - Detected error count and word count.
   - Edit density per 100 words (`(errors / words) * 100`).
   - Error-free token ratio (`1.0 - (errors / words)`).
   - Real sequence model confidence percentage.

6. **Live Benchmark Evaluation Modal**:
   - Run model evaluation across the held-out test set or demonstration pairs directly from the UI.
   - Displays real Corpus GLEU, BLEU, $F_{0.5}$ score, and sample predictions table.

## Development & Build

```powershell
cd grammar-error-detection-correction/frontend

# Install dependencies (if not done)
npm install

# Start Vite dev server
npm run dev

# Build production assets
npm run build
```
