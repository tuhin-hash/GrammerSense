# Grammar Error Detection & Correction Datasets

This directory manages the datasets used for training, fine-tuning, and evaluating the GEC/GED system.

## Directory Structure
- `demo/demo_pairs.jsonl`: Small demonstration dataset covering key grammatical error types and correct sentences for immediate offline testing.
- `raw/`: Unprocessed downloaded benchmark datasets (e.g. JFLEG, CoNLL, or synthetic pairs).
- `processed/`: Formatted, cleaned, and non-overlapping `train.jsonl`, `val.jsonl`, and `test.jsonl` splits.

## Dataset Schema
Each entry in `.jsonl` files follows this JSON schema:
```json
{
  "id": "sample-001",
  "source": "She go to college every day.",
  "target": "She goes to college every day.",
  "error_type": "Subject-Verb Agreement",
  "verification_tier": "DIRECTLY_IDENTIFIED"
}
```

### Verification Tiers
- **`DIRECTLY_IDENTIFIED`**: High-confidence linguistic errors verified by grammatical/morphological rules (e.g., singular subject with plural verb form).
- **`INFERRED`**: Inferred by sequence-to-sequence model divergence, complex phrasing or statistical alignment.
- **`CORRECT`**: Sentences verified as grammatically sound without edits.

## Anti-Leakage Protocol
Data splits generated by `scripts/prepare_data.py` enforce:
1. Strict SHA-256 sentence-level deduplication.
2. Group-based splitting ensuring identical or normalized source sentences never appear in both train and validation/test sets.
3. Fixed random seed (`42`) for full reproducibility.
